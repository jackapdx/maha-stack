# prototype-perf - Maha-Perf Developer Guide

## Commands
- **Dev:** `npm run dev` (Starts both API and Web)
- **Build:** `npm run build`

## Project Structure
- `apps/api/`: Hono API + tRPC Server
- `apps/web/`: React + tRPC Client

## Tech Stack
- Frontend: React 19 + Vite
- Backend: Hono + tRPC
- Validation: Zod
